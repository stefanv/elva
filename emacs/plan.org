#+TITLE: Elva Emacs Client - Development Plan
#+#+DATE: 2026-02-02

* Overview

This document tracks the plan for building a native Emacs client for Elva
using pycrdt (Python bindings to yrs/Rust Yjs implementation).

** Architecture

Web clients connect directly to Elva via WebSocket using y-protocols:

#+begin_src
┌─────────────┐
│ Web Client  │ ──────── WebSocket (y-protocols) ─────────┐
│   (Yjs)     │                                           │
└─────────────┘                                           ▼
                                                    ┌─────────┐
┌─────────────┐                                     │  Elva   │
│ Web Client  │ ──────── WebSocket (y-protocols) ──►│ (server)│
│   (Yjs)     │                                     │  pycrdt │
└─────────────┘                                     └─────────┘
#+end_src

Emacs lacks a native Yjs implementation, so we add a bridge subprocess:

#+begin_src
┌─────────────┐    JSON/stdio     ┌──────────────┐    WebSocket     ┌─────────┐
│   Emacs     │◄─────────────────►│ elva-bridge  │◄────────────────►│  Elva   │
│  (elva.el)  │  insert/delete    │  (pycrdt)    │   y-protocols    │ (server)│
└─────────────┘                   └──────────────┘                  └─────────┘
#+end_src

The bridge is a per-buffer subprocess that translates between Emacs's
position-based edits and Yjs's CRDT protocol.

** Why this approach?

We initially tried to bridge crdt.el (existing Emacs CRDT package) with Elva,
but discovered fundamental incompatibilities:

1. crdt.el uses its own CRDT with ID-based ordering (site-id, clock)
2. Yjs uses a different CRDT algorithm
3. Position-based bridging fails because the two CRDTs order content differently
4. Proper bridging would require complex ID translation between incompatible systems

The cleaner solution: use pycrdt as a subprocess that speaks native Yjs protocol.

* Technical Notes

** Position Indexing
- Emacs uses 1-based character positions (point starts at 1)
- pycrdt uses 0-based UTF-8 byte positions
- Bridge converts between them:
  - Emacs char pos → UTF-8 byte pos: encode prefix, count bytes
  - UTF-8 byte pos → Emacs char pos: decode prefix, count chars
  - elva.el adds/subtracts 1 for Emacs's 1-based indexing

** Echo Prevention
Both sides need to avoid re-sending changes they just received:
- elva.el: ~elva--applying-remote~ flag
- elva-bridge.py: ~_applying_remote~ flag

** Dependencies
- Python 3.8+
- pycrdt: ~pip install pycrdt~
- websockets: ~pip install websockets~

** Awareness Protocol
Cursor positions are shared via the Yjs awareness protocol:
- Positions stored as UTF-8 byte offsets: ~{"cursor": {"anchor": pos, "head": pos}}~
- Bridge converts byte positions to Emacs char positions
- Stale awareness entries cleared on connect (prevents phantom cursors)
- Disconnect message sent on shutdown (best effort)
- Cursor positions adjusted locally when edits happen (prevents "walking backward")
